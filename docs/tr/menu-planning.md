# Menü planlama

## 1. Amaç

**Menü planlama** (haftalık): **Tarifler**den yemekleri **Kahvaltı / Öğle / Akşam** slotlarına (Pzt–Paz) yerleştirme, **pişirme yok** günleri, **haftalık özet**, başka haftadan **kopyalama**.

## 2. Ne zaman?

- Alışveriş öncesi haftalık plan.
- **Tarifler**de en az **bir tarif** yoksa yeni plan oluşturulamaz.

## 3. Ekranlar

- **İşlevler** → **Menü planlama** — liste (yaklaşan / güncel / geçmiş)
- **Haftalık menü oluştur** — başlangıç tarihi, isteğe bağlı kopya
- **Detay** — gün/öğün ızgarası; dışarıdan yemek; pişirme yok; özet; önceki hafta

## 4. Kullanım

**Oluştur** → tarih → tarih çakışması = hata. Tarif yoksa engellenir.

Slot → **Tarif seç** veya **Dışarıdan yemek**.

**Bu gün pişirme yok** — uyarı; **Tekrar pişirmeyi aç**.

Listeden haftayı sil.

**12 plan limiti** — iletişim kutusu.

## 5. Örnek

```text
[ Hafta: 03/01 – 09/01 ]  [🟢 Güncel]
```

## 6. Mantık

- 7 gün; çakışan aralık yok.
- **Tarifler**den veya serbest metin dışarıdan.

## 7. Notlar

- **Premium** mümkün.
- İlk plandan önce tarif ekleyin.
