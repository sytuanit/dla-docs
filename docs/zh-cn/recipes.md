# 菜谱

## 1. 目的

**菜谱**用于保存**烹饪菜谱**（菜名、食材、做法）、**蛋白质类型**、**星级评分**，并用**收藏**整理菜品。数据与**菜单计划**共用，用于分配到一周各餐。

## 2. 何时使用

- 需要个人菜谱本，做饭时查阅。
- 用**收藏**按主题分组。
- 使用**菜单计划**前，需先在**菜谱**中创建**至少若干道菜**。

## 3. 相关界面

- **功能** → **厨房与餐饮** → **菜谱**
- **菜谱** / **收藏**标签
- **添加菜谱** / **编辑**
- **收藏详情**

## 4. 主要操作

**功能** → **菜谱** → **搜索菜谱…**；**收藏**标签可单独搜索。

**+**（FAB）→ **菜名**（必填）、**蛋白质类型**（可选，逗号分隔）、**评分**、**食材**（至少一行）、**做法**、**收藏** → **保存**。

点击菜品进入编辑。**删除**若菜品在**周菜单**中使用会有提示。

**收藏** → 新建；进入 → **添加菜品**；重命名/删除收藏（不删除菜品本身）。

## 5. 示例

```text
[ 菜谱 ]  [ 收藏 ]
[ 搜索菜谱…______________________________ ]

┌────────────────────────────────────────────┐
│ 冬阴功汤                            [ x ] │
│ ★★★★☆  ·  蛋白质：海鲜                  │
│ 5 种食材  ·  收藏：泰式                 │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. 逻辑与规则

- 至少**一条食材**。
- 删除周菜单中的菜品需确认。

## 7. 注意

- **高级版**可能在**功能**页显示标识。
