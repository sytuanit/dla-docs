# ສູດອາຫານ

## 1. ຈຸດປະສົງ

ໂມດູນ **ສະດາອາຫານ** ໃຫ້ທ່ານເກັບ **ສູດປຸງ** (ຊື່, ວັດຖຸດິບ, ວິທີປຸງ), **ປະເພດໂປຣຕີນ**, **ໃຫ້ຄະແນນດາວ**, ແລະ ຈັດເປັນ **ຊຸດສະສົມ**. ຂໍ້ມູນໃຊ້ຮ່ວມກັບ **ແຜນອາຫານຕາມອາທິດ** ເມື່ອເລືອກມື້ໃນແຕ່ລະມື້ຂອງອາທິດ.

## 2. ເມື່ອໃດຄວນໃຊ້

- ຕ້ອງການປຶ້ມສູດສ່ວນຕົວ.
- ຈັດກຸ່ມດ້ວຍ **ຊຸດສະສົມ**.
- ກ່ອນໃຊ້ **ແຜນອາຫານ** ຕ້ອງມີ **ຢ່າງໜ້ອຍບາງສະດາ** ໃນ **ສະດາອາຫານ** ກ່ອນ.

## 3. ໜ້າຈໍທີ່ກ່ຽວຂ້ອງ

- **ຟັງຊັນ** → **ຄົວ** → **ສະດາອາຫານ**
- ແຖບ **ສະດາທັງໝົດ** / **ຊຸດສະສົມ**
- **ເພີ່ມສະດາ** / **ແກ້ໄຂ**
- **ລາຍລະອຽດຊຸດສະສົມ**

## 4. ວິທີໃຊ້ຫຼັກ

**ຟັງຊັນ** → **ສະດາອາຫານ** → **ຄົ້ນຫາ...** ; ແຖບ **ຊຸດສະສົມ**

**+** (FAB) → **ຊື່ເມນູ** (ຈຳເປັນ), **ໂປຣຕີນ**, **ຄະແນນ**, **ວັດຖຸດິບ** (ຢ່າງໜ້ອຍແຖວໜຶ່ງ), **ວິທີປຸງ**, **ຊຸດສະສົມ** → **ບັນທຶກ**

ແຕະສະດາເພື່ອແກ້ໄຂ. **ລຶບ** ຖ້າຢູ່ໃນ **ແຜນອາຫານ** ຈະມີຄຳເຕືອນ.

**ຊຸດສະສົມ** → ສ້າງໃໝ່; ເປີດ → **ເພີ່ມສະດາ**; ປ່ຽນຊື່/ລຶບຊຸດ (ບໍ່ລຶບສະດາ).

## 5. ຕົວຢ່າງ

```text
[ ສະດາ ]  [ ຊຸດສະສົມ ]
[ ຄົ້ນຫາ...____________________________ ]

┌────────────────────────────────────────────┐
│ ຕົ້ມຍຳກຸ້ງ                      [ x ]    │
│ ★★★★☆  ·  ໂປຣຕີນ: ທະເລ                  │
│ 5 ລາຍການ  ·  ຊຸດ: ໄທ                   │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. ກົດລະບຽບ

- ຕ້ອງມີ **ວັດຖຸດິບຢ່າງໜ້ອຍໜຶ່ງ**.
- ລຶບສະດາທີ່ໃຊ້ໃນແຜນ: ຕ້ອງຢືນຢັນ.

## 7. ໝາຍເຫດ

- ອາດມີ **ພຣີເມຍມ** ທີ່ **ຟັງຊັນ**
