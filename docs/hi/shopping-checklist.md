# खरीदारी (चेकलिस्ट)

## 1. उद्देश्य

**खरीदारी (चेकलिस्ट)**: सूची नाम और वस्तुएँ, **खरीदा चिह्नित करें**, **संपादित करें**, **कॉपी**, **हटाएँ**। **विशेष अवसर** तैयारी चरण से जुड़े होने पर **हटाना नहीं**।

## 2. कब उपयोग करें

- स्पष्ट सूची के साथ खरीदारी।
- समान कार्यक्रमों के लिए कॉपी।
- तैयारी चरण में चेकलिस्ट।

## 3. स्क्रीन

- **कार्य** → **खरीदारी (चेकलिस्ट)**
- **बनाएँ / संपादित करें**
- **चेकलिस्ट उपयोग करें** — चिह्न, त्वरित जोड़, **रीसेट**
- **विशेष अवसर** — चेकलिस्ट चुनें

## 4. उपयोग

**+** → नाम → वस्तुएँ → **सहेजें**। **संपादित करें ›** कॉपी हटाएँ (जुड़ा हो तो ब्लॉक)। **खोजें...**

## 5. उदाहरण

```text
[ खोजें...______________________________ ]
┌────────────────────────────────────────────┐
│ नया साल              संपादित ›  [x]  │
│ 3 वस्तुएँ  0/3 खरीदी                    │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. नियम

- **रीसेट** पुष्टि के साथ।
- विशेष अवसर लिंक हटाने रोकता है।

## 7. ध्यान दें

- **प्रीमियम** संभव।
- वेब गाइड के लिए इंटरनेट।
