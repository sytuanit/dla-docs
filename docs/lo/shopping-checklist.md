# ຊື້ເຄື່ອງ (ເຊັກລິສ)

## 1. ຈຸດປະສົງ

**ຊື້ເຄື່ອງ (ເຊັກລິສ)**: ລາຍການ, **ຕິກເມື່ອຊື້ແລ້ວ**, **ແກ້ໄຂ**, **ສຳເນົາ**, **ລຶບ**. ຖ້າຜູກກັບ **ວັນພິເສດ** ບໍ່ໃຫ້ **ລຶບ** ຂະນະໃຊ້ງານ.

## 2. ເມື່ອໃດຄວນໃຊ້

- ຊື້ຕາມລາຍການຊັດເຈນ.
- ສຳເນົາສຳລັບງານຄ້າຍກັນ.
- ເຊື່ອມກັບຂັ້ນຕອນເຕຣີມວັນພິເສດ.

## 3. ໜ້າຈໍ

- **ຟັງຊັນ** → **ຊື້ເຄື່ອງ (ເຊັກລິສ)**
- **ສ້າງ / ແກ້ໄຂ**
- **ໃຊ້ເຊັກລິສ** — ຕິກ, ເພີ່ມໄວ, **ຣີເຊັດ**
- **ວັນພິເສດ** — ເລືອກເຊັກລິສ

## 4. ວິທີໃຊ້

**+** → ຊື່ → ລາຍການ → **ບັນທຶກ**. **ແກ້ໄຂ ›** ສຳເນົາ ລຶບ (ຖ້າຜູກກັນ = ບໍ່ໃຫ້). **ຄົ້ຫາເຊັກລິສ...**

## 5. ຕົວຢ່າງ

```text
[ ຄົ້ຫາ...______________________________ ]
┌────────────────────────────────────────────┐
│ ປີໃໝ່                  ແກ້ໄຂ ›      [x] │
│ 3 ລາຍການ  0/3 ຊື້ແລ້ວ                 │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. ກົດລະບຽບ

- **ຣີເຊັດ** ມີການຢືນຢັນ.
- ການຜູກວັນພິເສດບລັອກການລຶບ.

## 7. ໝາຍເຫດ

- **ພຣີເມຍມ** ເປັນໄດ້.
- ຄູ່ມືເວັບຕ້ອງອິນເຕີເນັດ.
