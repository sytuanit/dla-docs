# Pianificazione menu

## 1. Scopo

**Pianificazione menu** (settimanale): assegnare piatti dalle **Ricette** a **Colazione / Pranzo / Cena** per ogni giorno (lun–dom), **giorni senza cucina**, **riepilogo settimanale**, **copia** da un’altra settimana.

## 2. Quando usarlo

- Pianificare la spesa.
- Serve **almeno una ricetta** in **Ricette** per creare un nuovo piano.

## 3. Schermate

- **Funzioni** → **Pianificazione menu** — elenco piani (in arrivo / in corso / passato)
- **Crea piano settimanale** — data inizio, copia opzionale
- **Dettaglio** — griglia giorno/pasto; pasti esterni; giorno libero; riepilogo; settimana precedente

## 4. Uso

**Funzioni** → **Pianificazione menu** → **Crea** → data → copia opzionale → sovrapposizione date = errore. Senza ricette: blocco.

Toccare slot → **Scegli ricetta** o **Pasto fuori**.

**Non cucinare questo giorno** con avviso; **Riattiva cucina**.

Eliminare settimana dall’elenco.

**Limite 12 piani** — dialogo possibile.

## 5. Esempio

```text
[ Settimana: 03/01 – 09/01 ]  [🟢 In corso]
        Lun   Mar   Mer
Col.    [+]   [+]   [+]
Pranzo  [+] [Tom yum][+]
Cena    [+]   [+]   [+]
```

## 6. Logica

- 7 giorni; nessuna sovrapposizione tra piani.
- Piatti da **Ricette**; testo libero per esterni.

## 7. Note

- **Premium** possibile.
- Creare ricette prima del primo piano.
