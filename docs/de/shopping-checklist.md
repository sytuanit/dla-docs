# Einkaufen (Checkliste)

## 1. Zweck

**Einkaufen (Checkliste)**: **Einkaufslisten** mit Punkten, **abhaken**, **bearbeiten**, **duplizieren**, **löschen**. Verknüpfung mit **Besondere Anlässe** — **Löschen gesperrt**, solange verwendet.

## 2. Wann nutzen?

- Einkauf mit klarer Liste.
- Listen duplizieren für ähnliche Anlässe.
- Checkliste in Vorbereitungsschritten eines Anlasses.

## 3. Bildschirme

- **Funktionen** → **Einkaufen (Checkliste)**
- **Erstellen / Bearbeiten**
- **Checkliste nutzen** — abhaken, Schnell hinzufügen, **Zurücksetzen**
- **Besondere Anlässe** — Auswahl der Checkliste

## 4. Hauptbedienung

### 4.1 Neu

**+** → Name → Punkte → **Speichern**.

### 4.2 Nutzen

Liste antippen → abhaken; **Schnell hinzufügen**; **Zurücksetzen** (Bestätigung).

### 4.3 Bearbeiten

**Bearbeiten ›** → **Speichern**.

### 4.4 Duplizieren

Aus vorhandener Liste kopieren → umbenennen → speichern.

### 4.5 Löschen

Bei Verknüpfung mit Anlass: **Löschen nicht möglich** (Meldung).

### 4.6 Suche

**Checklisten suchen...**

## 5. Beispiele

```text
[ Suche..._______________________________ ]
┌──────────────────────────────────────────┐
│ Silvester                    Bearb. › [x]│
│ 3 Punkte   0/3 erledigt                  │
└──────────────────────────────────────────┘
                                           [ + ]
```

## 6. Logik

- Punkte erledigt/offen; **Zurücksetzen** mit Bestätigung.
- Anlass-Verknüpfung blockiert Löschen.
- Duplikat erzeugt neue Liste.

## 7. Hinweise

- **Premium** möglich.
- Web-Hilfe braucht Internet; Checkliste in der App offline nutzbar nach Laden.
