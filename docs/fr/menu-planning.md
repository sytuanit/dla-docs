# Planification des menus

## 1. Objectif

**Planification des menus** (hebdomadaire) : placer des plats des **Recettes** dans **Petit-déjeuner / Déjeuner / Dîner** chaque jour (lundi–dimanche), marquer des **jours sans cuisine**, consulter le **résumé hebdomadaire** et **copier** depuis une autre semaine.

## 2. Quand l’utiliser

- Anticiper les courses.
- Au moins **une recette** dans **Recettes** pour créer un nouveau plan.

## 3. Écrans

- **Fonctions** → **Planification des menus** — liste des semaines (à venir / en cours / passé)
- **Créer un menu hebdomadaire** — date de début, copie optionnelle
- **Détail** — grille jour/repas ; repas extérieur ; jour sans cuisine ; synthèse ; semaine précédente

## 4. Utilisation

Créer : **Fonctions** → **Planification des menus** → **Créer** → date → option **Copier** → chevauchement = erreur. Sans recettes : création bloquée.

Assigner : toucher un créneau → **Choisir une recette** ou **Repas extérieur**.

**Pas de cuisine ce jour** : raison optionnelle ; avertissement si suppression des plats du jour.

Supprimer une semaine depuis la liste.

**Limite** : **12 plans** — dialogue possible.

## 5. Exemple

```text
[ Semaine : 03/01 – 09/01 ]  [🟢 En cours]
        Lun   Mar   Mer
Matin   [+]   [+]   [+]
Midi    [+] [Tom yum][+]
Soir    [+]   [+]   [+]
```

## 6. Logique

- 7 jours ; pas de chevauchement entre plans.
- Plats issus des **Recettes** ; texte libre pour l’extérieur.
- Limite **12** — voir dialogue.

## 7. Notes

- **Premium** possible.
- Créez des recettes avant le premier plan.
