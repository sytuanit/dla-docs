# Perencanaan menu

## 1. Tujuan

**Perencanaan menu** (mingguan): menempatkan hidangan dari **Resep** ke **Sarapan / Makan siang / Makan malam** harian (Sen–Min), **hari tidak memasak**, **ringkasan mingguan**, **salin** dari minggu lain.

## 2. Kapan digunakan

- Merencanakan sebelum belanja.
- Perlu **minimal satu resep** di **Resep**.

## 3. Layar

- **Fungsi** → **Perencanaan menu** — daftar (mendatang / berlangsung / lalu)
- **Buat menu mingguan** — tanggal mulai, salin opsional
- **Detail** — grid hari/waktu makan; makan luar; hari libur masak; ringkasan; minggu sebelumnya

## 4. Penggunaan

**Fungsi** → **Perencanaan menu** → **Buat** → tanggal → salin opsional → tumpang tindih tanggal = error. Tanpa resep: diblokir.

Ketuk slot → **Pilih resep** atau **Makan luar**.

**Tidak memasak hari ini** — peringatan; **Nyalakan lagi memasak**.

Hapus minggu dari daftar.

**Batas 12 menu** — dialog mungkin muncul.

## 5. Contoh

```text
[ Minggu: 03/01 – 09/01 ]  [🟢 Berlangsung]
```

## 6. Logika

- 7 hari; tidak tumpang tindih.
- Hidangan dari **Resep**; teks bebas untuk luar.

## 7. Catatan

- **Premium** mungkin.
- Buat resep sebelum menu pertama.
