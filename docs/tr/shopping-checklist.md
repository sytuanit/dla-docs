# Alışveriş (kontrol listesi)

## 1. Amaç

**Alışveriş (kontrol listesi)**: madde listeleri, **işaretle**, **düzenle**, **çoğalt**, **sil**. **Özel günler** ile bağlantı — kullanımda **silme engellenir**.

## 2. Ne zaman?

- Net liste ile market.
- Benzer etkinlikler için çoğaltma.
- Hazırlık adımında checklist.

## 3. Ekranlar

- **İşlevler** → **Alışveriş (kontrol listesi)**
- **Oluştur / Düzenle**
- **Listeyi kullan** — işaretle, hızlı ekle, **Sıfırla**
- **Özel günler** — checklist seçimi

## 4. Kullanım

**+** → ad → maddeler → **Kaydet**. **Düzenle ›**; kopyala; sil (bağlıysa engellenir). **Liste ara...**

## 5. Örnek

```text
[ Ara..._________________________________ ]
┌────────────────────────────────────────────┐
│ Yılbaşı                  Düzenle ›    [x] │
│ 3 madde  0/3 tamam                        │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. Mantık

- **Sıfırla** onaylı.
- Özel gün bağlantısı silmeyi engeller.

## 7. Notlar

- **Premium** mümkün.
- Web kılavuzu internet ister.
