# Planeamento de ementas

## 1. Finalidade

**Planeamento de ementas** (semanal): atribuir pratos das **Receitas** a **Pequeno-almoço / Almoço / Jantar** por dia (seg–dom), **dias sem cozinhar**, **resumo semanal** e **copiar** de outra semana.

## 2. Quando usar

- Planear a semana antes das compras.
- Precisa de **pelo menos uma receita** em **Receitas**.

## 3. Ecrãs

- **Funções** → **Planeamento de ementas** — lista (futuro / atual / passado)
- **Criar ementa semanal** — data início, cópia opcional
- **Detalhe** — grelha dia/refeição; refeições externas; dia livre; resumo; semana anterior

## 4. Utilização

**Funções** → **Planeamento de ementas** → **Criar** → data → cópia opcional → sobreposição = erro. Sem receitas: bloqueado.

Toque no slot → **Escolher receita** ou **Refeição fora**.

**Não cozinhar neste dia** com aviso; **Voltar a cozinhar**.

Eliminar semana na lista.

**Limite 12 ementas** — diálogo possível.

## 5. Exemplo

```text
[ Semana: 03/01 – 09/01 ]  [🟢 Atual]
        Seg   Ter   Qua
Peq.    [+]   [+]   [+]
Almoço  [+] [Tom yum][+]
Jantar  [+]   [+]   [+]
```

## 6. Lógica

- 7 dias; sem sobreposição.
- Pratos das **Receitas**; texto livre para fora.

## 7. Notas

- **Premium** possível.
- Crie receitas antes do primeiro plano.
