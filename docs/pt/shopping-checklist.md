# Compras (lista)

## 1. Finalidade

**Compras (lista)**: listas com itens, **marcar**, **editar**, **duplicar**, **eliminar**. Ligação a **Ocasiões especiais** — **eliminação bloqueada** em uso.

## 2. Quando usar

- Compras com lista clara.
- Duplicar para eventos semelhantes.
- Checklist em passos de preparação.

## 3. Ecrãs

- **Funções** → **Compras (lista)**
- **Criar / Editar**
- **Usar lista** — marcar, adição rápida, **Repor**
- **Ocasiões especiais** — escolher checklist

## 4. Utilização

**+** → nome → itens → **Guardar**. **Editar ›**; cópia; eliminar (bloqueado se ligado). **Pesquisar listas...**

## 5. Exemplo

```text
[ Pesquisar...___________________________ ]
┌────────────────────────────────────────────┐
│ Passagem de ano              Editar ›  [x] │
│ 3 itens  0/3 feitos                       │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. Lógica

- **Repor** com confirmação.
- Ligação bloqueia eliminação.
