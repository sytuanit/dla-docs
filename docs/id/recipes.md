# Resep

## 1. Tujuan

Modul **Resep** menyimpan **resep masakan** (nama, bahan, cara memasak), **jenis protein**, **rating bintang**, dan **koleksi** resep. Data dipakai bersama **Perencanaan menu** untuk mingguan.

## 2. Kapan digunakan

- Buku resep pribadi.
- Mengelompokkan dengan **koleksi**.
- **Perencanaan menu** memerlukan **minimal beberapa resep** terlebih dahulu.

## 3. Layar terkait

- **Fungsi** → **Dapur & kuliner** → **Resep**
- Tab **Resep** / **Koleksi**
- **Tambah resep** / **Edit**
- **Detail koleksi**

## 4. Penggunaan utama

**Fungsi** → **Resep** → **Cari resep...** ; tab **Koleksi**.

**+** (FAB) → **Nama hidangan** (wajib), **Protein** (opsional, koma), **Rating**, **Bahan** (minimal satu baris), **Cara memasak**, **Koleksi** → **Simpan**.

Ketuk resep untuk edit. **Hapus** dengan peringatan jika dipakai di **menu mingguan**.

**Koleksi** → buat; buka → **Tambah resep**; rename/hapus koleksi (resep tidak terhapus).

## 5. Contoh

```text
[ Resep ]  [ Koleksi ]
[ Cari...________________________________ ]

┌────────────────────────────────────────────┐
│ Sup tom yum                        [ x ]  │
│ ★★★★☆  ·  Protein: seafood               │
│ 5 bahan  ·  Koleksi: Thai                │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. Logika

- **Minimal satu bahan**.
- Hapus resep yang dipakai di menu: konfirmasi.

## 7. Catatan

- **Premium** mungkin di **Fungsi**.
