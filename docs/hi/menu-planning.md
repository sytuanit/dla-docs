# मेनू योजना

## 1. उद्देश्य

**मेनू योजना** (साप्ताहिक): **रेसिपी** से व्यंजन को प्रत्येक दिन **सुबह / दोपहर / शाम** (सोम–रवि) में रखें, **न खाना पकाने** के दिन चिह्नित करें, **साप्ताहिक सारांश** देखें, पिछले सप्ताह से **कॉपी** करें।

## 2. कब उपयोग करें

- खरीदारी से पहले सप्ताह भर की योजना।
- नई योजना के लिए **रेसिपी** में **कम से कम एक रेसिपी** होनी चाहिए।

## 3. स्क्रीन

- **कार्य** → **मेनू योजना** — सूची (आगामी / चालू / पिछला)
- **साप्ताहिक योजना बनाएँ** — प्रारंभ तिथि, वैकल्पिक कॉपी
- **विवरण** — दिन×भोजन ग्रिड; बाहर का खाना; छुट्टी; सारांश; पिछला सप्ताह

## 4. उपयोग

**बनाएँ** → तिथि → **ओवरलैप** = त्रुटि। रेसिपी नहीं = रोक।

स्लॉट टैप → **रेसिपी चुनें** या **बाहर का भोजन**।

**इस दिन खाना नहीं** — चेतावनी; **फिर से पकाना**।

सूची से सप्ताह हटाएँ।

**12 योजना सीमा** — संवाद संभव।

## 5. उदाहरण

```text
[ सप्ताह: 03/01 – 09/01 ]  [🟢 चालू]
```

## 6. नियम

- 7 दिन; अन्य योजना से तिथि नहीं मिलनी चाहिए।
- व्यंजन **रेसिपी** से; बाहर टेक्स्ट।

## 7. ध्यान दें

- **प्रीमियम** संभव।
- पहली योजना से पहले रेसिपी जोड़ें।
