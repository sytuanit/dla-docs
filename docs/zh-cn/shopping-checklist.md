# 购物（清单）

## 1. 目的

**购物（清单）**：创建购物**清单**（名称、条目），**勾选已购**，**编辑**、**复制**、**删除**。若与**特殊场合**的准备步骤关联，则**不可删除**。

## 2. 何时使用

- 超市/菜场按清单采购。
- 复制清单用于相似场合。
- 在准备步骤中关联清单。

## 3. 相关界面

- **功能** → **购物（清单）**
- **创建 / 编辑**
- **使用清单** — 勾选、快速添加、**重置**
- **特殊场合** — 选择清单

## 4. 主要操作

**+** → 名称 → 条目 → **保存**。**编辑 ›**；从已有清单复制；删除（若被占用则禁止）。**搜索清单…**

## 5. 示例

```text
[ 搜索清单…______________________________ ]
┌────────────────────────────────────────────┐
│ 跨年聚会                        编辑 › [x] │
│ 3 条  0/3 已购                            │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. 逻辑与规则

- **重置**需确认，取消全部已购标记。
- 关联特殊场合时禁止删除。

## 7. 注意

- 可能标**高级版**。
- 在线用户指南需网络；清单在应用内正常使用。
