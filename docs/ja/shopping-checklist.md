# 買い物（チェックリスト）

## 1. 目的

**買い物（チェックリスト）**：リスト名と項目、**チェック**、**編集**、**コピー**、**削除**。**特別な日**の準備ステップと紐づいていると**削除できません**。

## 2. 使うタイミング

- スーパー・市場でリストどおり買う。
- 似たイベント用にコピーして再利用。
- 準備ステップにチェックリストを割り当てる。

## 3. 関連画面

- **機能** → **買い物（チェックリスト）**
- **作成 / 編集**
- **チェックリストを使う** — チェック、クイック追加、**リセット**
- **特別な日** — リスト選択

## 4. 主な操作

**+** → 名前 → 項目 → **保存**。**編集 ›**；既存からコピー；削除（使用中は不可）。**チェックリストを検索...**

## 5. 例

```text
[ 検索...__________________________________ ]
┌────────────────────────────────────────────┐
│ 大晦日                    編集 ›      [x] │
│ 3項目  0/3 完了                          │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. ロジック

- **リセット**は確認あり。
- 特別な日に使用中は削除不可。

## 7. 注意

- **プレミアム**の場合あり。
- Webヘルプはインターネットが必要です。
