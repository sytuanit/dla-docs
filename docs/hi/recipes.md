# व्यंजन / रेसिपी

## 1. उद्देश्य

**रेसिपी** मॉड्यूल **खाना पकाने की रेसिपी** (नाम, सामग्री, विधि), **प्रोटीन प्रकार**, **स्टार रेटिंग** और **संग्रह** से व्यंजन व्यवस्थित करता है। डेटा **मेनू योजना** में सप्ताह के भोजन स्लॉट के लिए साझा होता है।

## 2. कब उपयोग करें

- व्यक्तिगत रेसिपी नोटबुक।
- **संग्रह** से विषयवार समूह।
- **मेनू योजना** से पहले **रेसिपी** में **कम से कम कुछ व्यंजन** चाहिए।

## 3. संबंधित स्क्रीन

- **कार्य** → **रसोई** → **रेसिपी**
- **रेसिपी** / **संग्रह** टैब
- **रेसिपी जोड़ें** / **संपादित करें**
- **संग्रह विवरण**

## 4. मुख्य उपयोग

**कार्य** → **रेसिपी** → **खोजें...** ; **संग्रह** टैब।

**+** (FAB) → **नाम** (आवश्यक), **प्रोटीन** (वैकल्पिक), **रेटिंग**, **सामग्री** (कम से कम एक पंक्ति), **विधि**, **संग्रह** → **सहेजें**।

रेसिपी पर टैप कर संपादित करें। **हटाएँ** जब **साप्ताहिक योजना** में हो तो चेतावनी।

**संग्रह** → नया बनाएँ; खोलें → **रेसिपी जोड़ें**; नाम बदलें/संग्रह हटाएँ (व्यंजन नहीं हटते)।

## 5. उदाहरण

```text
[ रेसिपी ]  [ संग्रह ]
[ खोजें...______________________________ ]

┌────────────────────────────────────────────┐
│ टॉम यम सूप                    [ x ]      │
│ ★★★★☆  ·  प्रोटीन: समुद्री                 │
│ 5 सामग्री  ·  संग्रह: थाई                │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. नियम

- **कम से कम एक सामग्री** आवश्यक।
- योजना में उपयोगित व्यंजन हटाने पर पुष्टि।

## 7. ध्यान दें

- **प्रीमियम** **कार्य** पर बैज हो सकता है।
