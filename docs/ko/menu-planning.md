# 식단 계획

## 1. 목적

**식단 계획**(주간): **레시피** 요리를 매일 **아침 / 점심 / 저녁**(월~일)에 배치하고, **요리 안 하는 날**, **주간 요약**, 다른 주에서 **복사**할 수 있습니다.

## 2. 언제 쓰나요

- 장보기 전 주간 식단을 짤 때.
- 새 계획에는 **레시피가 최소 1개** 있어야 합니다.

## 3. 관련 화면

- **기능** → **식단 계획** — 목록(예정 / 진행 중 / 지난 주)
- **주간 식단 만들기** — 시작일, 선택적 복사
- **상세** — 요일×끼니 격자; 외식; 쉬는 날; 요약; 이전 주

## 4. 주요 사용법

**만들기** → 시작일 → 날짜 **겹침** 시 오류. 레시피 없으면 만들기 불가.

슬롯 탭 → **레시피 선택** 또는 **외식 메모**.

**이날은 요리 안 함** — 안내 후 해당 날 메뉴 삭제; **다시 요리**로 복구.

목록에서 주 삭제.

**12개 제한** — 대화상자가 뜰 수 있음.

## 5. 예시

```text
[ 주: 01/03 – 01/09 ]  [🟢 이번 주]
```

## 6. 규칙

- 7일; 다른 계획과 기간 겹침 불가.
- 요리는 **레시피**에서; 외식은 자유 입력.

## 7. 참고

- **프리미엄** 가능.
- 첫 식단 전에 레시피를 만드세요.
