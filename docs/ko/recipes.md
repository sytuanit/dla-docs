# 레시피

## 1. 목적

**레시피**에서는 **요리 레시피**(이름, 재료, 조리법), **단백질 종류**, **별점**, **컬렉션**으로 요리를 정리합니다. **식단 계획**에서 주간 식사에 넣을 때 같은 데이터를 사용합니다.

## 2. 언제 쓰나요

- 요리할 때 바로 보는 나만의 레시피 노트.
- **컬렉션**으로 주제별 묶기.
- **식단 계획**을 쓰려면 **레시피를 먼저** 몇 개 이상 만들어야 합니다.

## 3. 관련 화면

- **기능** → **주방 및 요리** → **레시피**
- **레시피** / **컬렉션** 탭
- **레시피 추가** / **편집**
- **컬렉션 상세**

## 4. 주요 사용법

**기능** → **레시피** → **레시피 검색...** ; **컬렉션** 탭에 별도 검색.

**+**(FAB) → **요리 이름**(필수), **단백질**(선택·쉼표), **평점**, **재료**(최소 1행), **조리법**, **컬렉션** → **저장**.

레시피를 탭해 편집.**삭제** 시 **식단**에 들어 있으면 경고.

**컬렉션** → 만들기; 열기 → **레시피 추가**; 이름 변경/삭제(요리 자체는 삭제되지 않음).

## 5. 예시

```text
[ 레시피 ]  [ 컬렉션 ]
[ 검색...________________________________ ]

┌────────────────────────────────────────────┐
│ 똠얌꿍                              [ x ] │
│ ★★★★☆  ·  단백질: 해산물                 │
│ 재료 5개  ·  컬렉션: 태국                │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. 규칙

- **재료는 최소 1개** 필수.
- 식단에 쓰인 요리 삭제 시 확인.

## 7. 참고

- **프리미엄** 표시가 **기능**에 있을 수 있습니다.
