# 菜单计划

## 1. 目的

**菜单计划**（按周）：将**菜谱**中的菜分配到每日**早/午/晚**（周一至周日），可标记**不做饭日**、查看**周汇总**，并从已有周**复制**。

## 2. 何时使用

- 采购前规划一周。
- 新建计划前**菜谱**中需有**至少一道菜**。

## 3. 相关界面

- **功能** → **菜单计划** — 列表（即将开始/进行中/已结束）
- **创建周菜单** — 开始日期，可选复制来源
- **详情** — 按日×餐次网格；外食；不做饭日；汇总；上一周

## 4. 主要操作

**功能** → **菜单计划** → **创建** → 开始日期 → 可选**从已有计划复制** → 日期**重叠**会报错。无菜谱时无法创建。

点击餐次 → **选择菜谱**或**外食**（自由文本）。

**本日不做饭** — 可选原因；确认后当日已排菜会被移除；可**恢复做饭**。

在列表中删除某周。

**最多 12 份周计划** — 达上限可能出现对话框。

## 5. 示例

```text
[ 本周：01/03 – 01/09 ]  [🟢 进行中]
```

## 6. 逻辑与规则

- 7 天；与其他计划**日期区间不重叠**。
- 菜品来自**菜谱**；外食为自由文本。

## 7. 注意

- 可能标**高级版**。
- 首次计划前请先添加菜谱。
