# 購物（清單）

## 1. 目的

**購物（清單）**：建立清單（名稱、項目），**勾選已購**，**編輯**、**複製**、**刪除**。若與**特殊場合**的準備步驟連結，則**無法刪除**。

## 2. 何時使用

- 超市/市場依清單採購。
- 複製清單用於相似活動。
- 在準備步驟中連結清單。

## 3. 相關畫面

- **功能** → **購物（清單）**
- **建立 / 編輯**
- **使用清單** — 勾選、快速新增、**重設**
- **特殊場合** — 選擇清單

## 4. 主要操作

**+** → 名稱 → 項目 → **儲存**。**編輯 ›**；從既有複製；刪除（使用中會阻擋）。**搜尋清單…**

## 5. 範例

```text
[ 搜尋清單…______________________________ ]
┌────────────────────────────────────────────┐
│ 跨年派對                        編輯 ›  [x] │
│ 3 項  0/3 已購                           │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. 邏輯與規則

- **重設**需確認。
- 連結特殊場合時禁止刪除。

## 7. 注意

- 可能為**進階版**。
- 線上說明需網路；清單在 App 內正常使用。
