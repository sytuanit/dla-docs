# 菜單規劃

## 1. 目的

**菜單規劃**（依週）：將**食譜**菜色分配到每日**早/午/晚**（週一至週日），可標記**不開火日**、檢視**週摘要**，並從既有週**複製**。

## 2. 何時使用

- 採購前規劃一週。
- 新建前**食譜**需有**至少一道菜**。

## 3. 相關畫面

- **功能** → **菜單規劃** — 清單（即將/進行中/已結束）
- **建立週菜單** — 開始日期，可選複製來源
- **詳情** — 日×餐次格線；外食；不開火日；摘要；上一週

## 4. 主要操作

**功能** → **菜單規劃** → **建立** → 開始日 → 可選**複製** → 日期**重疊**會錯誤。無食譜時無法建立。

點餐次 → **選擇食譜**或**外食**（自由文字）。

**本日不做饭** — 可填原因；確認後當日已排菜會清除；可**恢復開火**。

從清單刪除某週。

**最多 12 份週計畫** — 達上限可能出現對話框。

## 5. 範例

```text
[ 本週：01/03 – 01/09 ]  [🟢 進行中]
```

## 6. 邏輯與規則

- 7 天；與其他計畫**區間不重疊**。
- 菜色來自**食譜**；外食為自由輸入。

## 7. 注意

- 可能為**進階版**。
- 首次週計畫前請先新增食譜。
