# Receitas

## 1. Finalidade

O módulo **Receitas** permite guardar **receitas de culinária** (nome, ingredientes, preparação), **tipos de proteína**, **classificação por estrelas** e organizar pratos em **coleções**. Os dados são partilhados com o **Planeamento de ementas** para as refeições da semana.

## 2. Quando usar

- Caderno pessoal de receitas.
- Agrupar pratos com **coleções**.
- Para **Planeamento de ementas** precisa de **pelo menos algumas receitas**.

## 3. Ecrãs

- **Funções** → **Cozinha e culinária** → **Receitas**
- Separadores **Receitas** / **Coleções**
- **Adicionar receita** / **Editar**
- **Detalhe da coleção**

## 4. Utilização principal

**Funções** → **Receitas** → **Pesquisar receitas...** ; **Coleções** com pesquisa própria.

**+** (FAB) → **Nome do prato** (obrigatório), **Proteínas** (opcional, vírgulas), **Classificação**, **Ingredientes** (pelo menos um), **Preparação**, **Coleções** → **Guardar**.

Toque num prato para editar. **Eliminar** com aviso se estiver no **plano semanal**.

**Coleções** → criar; abrir → **Adicionar receitas**; renomear/eliminar coleção (não elimina receitas).

## 5. Exemplo

```text
[ Receitas ]  [ Coleções ]
[ Pesquisar...____________________________ ]

┌────────────────────────────────────────────┐
│ Sopa tom yum                       [ x ]  │
│ ★★★★☆  ·  Proteína: marisco              │
│ 5 ingredientes  ·  Coleção: Tailandês    │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. Lógica

- **Pelo menos um ingrediente**.
- Eliminar prato usado no plano: confirmação.

## 7. Notas

- **Premium** possível em **Funções**.
