# Planificación de menús

## 1. Propósito

**Planificación de menús** (semanal): asignar platos de **Recetas** a **Desayuno / Comida / Cena** cada día (lunes a domingo), marcar **días sin cocinar**, ver **resumen semanal** y **copiar** desde otra semana.

## 2. Cuándo usarlo

- Planificar la semana antes de comprar.
- Necesitas **al menos una receta** en **Recetas** para crear un plan nuevo.

## 3. Pantallas

- **Funciones** → **Planificación de menús** — lista de planes (próximo / en curso / pasado)
- **Crear plan semanal** — fecha de inicio, copia opcional
- **Detalle** — rejilla día/comida; platos externos; día sin cocinar; resumen; semana anterior

## 4. Uso principal

### 4.1 Crear semana

**Funciones** → **Planificación de menús** → **Crear plan semanal** → fecha inicio → opcional **Copiar desde un plan** → solapamiento de fechas muestra error.

Sin recetas: no se puede crear.

### 4.2 Asignar platos

Toca **Desayuno / Comida / Cena** → **Elegir receta** o **Plato fuera de casa** (texto libre).

### 4.3 Día sin cocinar

**No cocinar este día** → motivo opcional → aviso borra platos del día; **Volver a cocinar**.

### 4.4 Resumen / semana anterior

**Resumen semanal** y **Semana anterior** según la app.

### 4.5 Eliminar

Eliminar semana en la lista — confirmar.

**Límite**: **12 planes** — diálogo posible al alcanzar el máximo.

## 5. Ejemplos

```text
[ Plan semanal: 03/01 – 09/01 ]  [🟢 En curso]
        Lun   Mar   Mié
Desay.  [+]   [+]   [+]
Comida  [+] [Tom yum][+]
Cena    [+]   [+]   [+]
```

## 6. Lógica

- 7 días; sin solapamiento con otro plan.
- Platos desde **Recetas**; externos como texto.
- Límite de **12** — ver mensaje en pantalla.

## 7. Notas

- **Premium** posible.
- Cree recetas antes del primer plan.
