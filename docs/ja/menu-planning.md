# メニュー計画

## 1. 目的

**メニュー計画**（週単位）：**レシピ**の料理を各日の**朝 / 昼 / 夜**（月～日）に配置し、**作らない日**、**週のまとめ**、別週からの**コピー**ができます。

## 2. 使うタイミング

- 買い物前に一週間分を決めたい。
- 新規作成には**レシピ**に**少なくとも1件**必要です。

## 3. 関連画面

- **機能** → **メニュー計画** — 一覧（予定 / 今週 / 過去）
- **週の献立を作成** — 開始日、任意でコピー元
- **詳細** — 日×食事のグリッド；外食；作らない日；まとめ；前の週

## 4. 主な操作

**作成** → 開始日 → 日付が**重複**するとエラー。レシピ0件では作成不可。

スロットをタップ → **料理を選ぶ**または**外食メモ**。

**この日は作らない** — 注意表示後、その日の料理が消えます。**再度オン**で戻せます。

一覧から週を削除。

**12件上限** — ダイアログが出る場合があります。

## 5. 例

```text
[ 週: 01/03 – 01/09 ]  [🟢 今週]
```

## 6. ロジック

- 7日間；別プランと期間重複不可。
- 料理は**レシピ**から；外食は自由入力。

## 7. 注意

- **プレミアム**の場合あり。
- 最初の献立の前にレシピを登録してください。
