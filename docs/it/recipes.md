# Ricette

## 1. Scopo

Il modulo **Ricette** consente di salvare **ricette** (nome, ingredienti, preparazione), **tipi di proteine**, **valutazione a stelle** e organizzare i piatti in **raccolte**. I dati sono condivisi con la **Pianificazione menu** per le settimane.

## 2. Quando usarlo

- Quaderno personale di ricette.
- Raggruppare i piatti con le **raccolte**.
- Per la **Pianificazione menu** servono **almeno alcune ricette** salvate.

## 3. Schermate

- **Funzioni** → **Cucina e gastronomia** → **Ricette**
- Schede **Ricette** / **Raccolte**
- **Aggiungi ricetta** / **Modifica**
- **Dettaglio raccolta**

## 4. Uso principale

**Funzioni** → **Ricette** → **Cerca ricette...** ; scheda **Raccolte**.

**+** (FAB) → **Nome piatto** (obbligatorio), **Proteine**, **Valutazione**, **Ingredienti** (almeno uno), **Preparazione**, **Raccolte** → **Salva**.

Modifica toccando un piatto. **Elimina** con avviso se il piatto è nel **menu settimanale**.

**Raccolte** → crea, aggiungi ricette, rinomina/elimina raccolta (non elimina le ricette).

## 5. Esempi

```text
[ Ricette ]  [ Raccolte ]
[ Cerca..._______________________________ ]

┌────────────────────────────────────────────┐
│ Zuppa tom yum                      [ x ]  │
│ ★★★★☆  ·  Proteine: pesce                 │
│ 5 ingredienti  ·  Raccolta: Thai          │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. Logica

- Almeno **un ingrediente**.
- Eliminazione piatto usato nel menu: conferma.
- Una ricetta in più **raccolte**.

## 7. Note

- **Premium** possibile su **Funzioni**.
