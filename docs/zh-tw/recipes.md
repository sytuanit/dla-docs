# 食譜

## 1. 目的

**食譜**可儲存**烹飪食譜**（菜名、食材、作法）、**蛋白質類型**、**星等評分**，並以**收藏**整理菜色。資料與**菜單規劃**共用，供分配到一週各餐。

## 2. 何時使用

- 個人食譜筆記，料理時查閱。
- 以**收藏**分主題。
- 使用**菜單規劃**前，請先在**食譜**建立**至少數道菜**。

## 3. 相關畫面

- **功能** → **廚房與餐飲** → **食譜**
- **食譜** / **收藏**分頁
- **新增食譜** / **編輯**
- **收藏詳情**

## 4. 主要操作

**功能** → **食譜** → **搜尋食譜…**；**收藏**分頁另有搜尋。

**+**（FAB）→ **菜名**（必填）、**蛋白質**（選填，逗號分隔）、**評分**、**食材**（至少一列）、**作法**、**收藏** → **儲存**。

點菜色進入編輯。**刪除**若該菜在**週菜單**中會有提示。

**收藏** → 新建；進入 → **新增菜色**；重新命名/刪除收藏（不刪除菜色本身）。

## 5. 範例

```text
[ 食譜 ]  [ 收藏 ]
[ 搜尋食譜…______________________________ ]

┌────────────────────────────────────────────┐
│ 冬蔭功                            [ x ] │
│ ★★★★☆  ·  蛋白質：海鮮                  │
│ 5 項食材  ·  收藏：泰式                 │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. 邏輯與規則

- 至少**一項食材**。
- 刪除週菜單中的菜色需確認。

## 7. 注意

- **進階版**可能在**功能**頁顯示。
