# レシピ

## 1. 目的

**レシピ**では**料理レシピ**（名前、材料、手順）、**たんぱく質の種類**、**星評価**、**コレクション**で料理を整理します。**献立計画**で週の各食事に割り当てる際に共通で使います。

## 2. 使うタイミング

- 料理中に見返す自分用レシピノートにしたい。
- **コレクション**でテーマ別にまとめたい。
- **献立計画**を使う前に、**いくつかレシピを登録**しておく必要があります。

## 3. 関連画面

- **機能** → **キッチン・料理** → **レシピ**
- **レシピ** / **コレクション**タブ
- **レシピを追加** / **編集**
- **コレクション詳細**

## 4. 主な操作

**機能** → **レシピ** → **レシピを検索...** ；**コレクション**タブで別検索。

**+**（FAB）→ **料理名**（必須）、**たんぱく質**（任意・カンマ区切り）、**評価**、**材料**（1行以上必須）、**手順**、**コレクション** → **保存**。

一覧でレシピをタップして編集。**削除**は**献立**で使っている場合に警告。

**コレクション** → 新規作成；開く → **レシピを追加**；名前変更/削除（レシピ本体は削除されません）。

## 5. 例

```text
[ レシピ ]  [ コレクション ]
[ レシピを検索...__________________________ ]

┌────────────────────────────────────────────┐
│ トムヤムクン                        [ x ]  │
│ ★★★★☆  ·  たんぱく質: 魚介              │
│ 材料5  ·  コレクション: タイ料理        │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. ロジック

- **材料は1つ以上**必須。
- 献立で使用中の料理を削除する場合は確認。

## 7. 注意

- **プレミアム**は**機能**画面に表示される場合があります。
