# 장보기 (체크리스트)

## 1. 목적

**장보기 (체크리스트)**: 목록 이름과 항목, **체크**, **편집**, **복사**, **삭제**. **특별한 날** 준비 단계와 연결되면 **삭제할 수 없습니다**.

## 2. 언제 쓰나요

- 마트·시장에서 목록대로 살 때.
- 비슷한 일정에 복사해 재사용.
- 준비 단계에 체크리스트 연결.

## 3. 관련 화면

- **기능** → **장보기 (체크리스트)**
- **만들기 / 편집**
- **체크리스트 사용** — 체크, 빠른 추가, **초기화**
- **특별한 날** — 목록 선택

## 4. 주요 사용법

**+** → 이름 → 항목 → **저장**. **편집 ›**; 복사; 삭제(연결 시 차단). **체크리스트 검색...**

## 5. 예시

```text
[ 검색...________________________________ ]
┌────────────────────────────────────────────┐
│ 송년회                    편집 ›       [x] │
│ 3개 항목  0/3 완료                       │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. 규칙

- **초기화**는 확인 후.
- 특별한 날에 쓰이면 삭제 불가.

## 7. 참고

- **프리미엄** 가능.
- 웹 안내는 인터넷 필요.
