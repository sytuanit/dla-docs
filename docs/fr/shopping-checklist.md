# Courses (check-list)

## 1. Objectif

**Courses (check-list)** : listes d’articles, **cocher**, **modifier**, **dupliquer**, **supprimer**. Liaison avec **Occasions spéciales** — **suppression impossible** tant que la liste est utilisée.

## 2. Quand l’utiliser

- Courses avec liste claire.
- Dupliquer pour des événements similaires.
- Liste liée à une étape de préparation.

## 3. Écrans

- **Fonctions** → **Courses (check-list)**
- **Créer / Modifier**
- **Utiliser la liste** — cocher, ajout rapide, **Réinitialiser**
- **Occasions spéciales** — choix de la liste

## 4. Utilisation

**+** → nom → articles → **Enregistrer**. Ouvrir une liste pour cocher ; **Modifier ›** ; copie depuis une liste ; **Supprimer** (bloqué si liaison). **Rechercher des listes...**

## 5. Exemple

```text
[ Recherche..._____________________________ ]
┌────────────────────────────────────────────┐
│ Réveillon                   Modifier › [x]│
│ 3 articles  0/3 cochés                    │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. Logique

- Articles cochés / non cochés ; **Réinitialiser** avec confirmation.
- Liaison occasion → suppression bloquée.
- Dupliquer = nouvelle liste.
