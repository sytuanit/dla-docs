# ช้อปปิ้ง (เช็กลิสต์)

## 1. วัตถุประสงค์

**ช้อปปิ้ง (เช็กลิสต์)**: รายการสินค้า, **ติ๊กเมื่อซื้อแล้ว**, **แก้ไข**, **คัดลอก**, **ลบ** หากผูกกับ **โอกาสพิเศษ** **ลบไม่ได้** ขณะใช้งาน

## 2. เมื่อไหร่ควรใช้

- ซื้อของตามรายการชัดเจน
- คัดลอกรายการสำหรับงานคล้ายกัน
- ผูกเช็กลิสต์กับขั้นตอนเตรียมโอกาสพิเศษ

## 3. หน้าจอ

- **ฟังก์ชัน** → **ช้อปปิ้ง (เช็กลิสต์)**
- **สร้าง / แก้ไข**
- **ใช้เช็กลิสต์** — ติ๊ก, เพิ่มด่วน, **รีเซ็ต**
- **โอกาสพิเศษ** — เลือกเช็กลิสต์

## 4. การใช้งาน

**+** → ชื่อ → รายการ → **บันทึก** **แก้ไข ›** คัดลอก ลบ (ถ้าถูกใช้ = ปฏิเสธ) **ค้นหาเช็กลิสต์...**

## 5. ตัวอย่าง

```text
[ ค้นหา...______________________________ ]
┌────────────────────────────────────────────┐
│ ปีใหม่                  แก้ไข ›      [x] │
│ 3 รายการ  0/3 ซื้อแล้ว                  │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. กฎ

- **รีเซ็ต** ยืนยันก่อน
- ผูกโอกาสพิเศษแล้วลบไม่ได้

## 7. หมายเหตุ

- **พรีเมียม** เป็นได้
- คู่มือบนเว็บต้องต่ออินเทอร์เน็ต
