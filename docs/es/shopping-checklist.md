# Compras (lista)

## 1. Propósito

**Compras (lista)**: listas con ítems, **marcar comprado**, **editar**, **duplicar**, **eliminar**. Vinculación con **Ocasiones especiales** — **no se puede eliminar** si está en uso.

## 2. Cuándo usarlo

- Compras con lista clara.
- Reutilizar listas duplicándolas.
- Checklist en pasos de preparación de un evento.

## 3. Pantallas

- **Funciones** → **Compras (lista)**
- **Crear / Editar**
- **Usar lista** — marcar, añadir rápido, **Restablecer**
- **Ocasiones especiales** — elegir checklist

## 4. Uso principal

**+** → nombre → ítems → **Guardar**. Toca lista para **usar**; **Editar ›**; **Copiar** desde lista; **Eliminar** (bloqueado si hay vínculo con ocasión). **Buscar listas...**

## 5. Ejemplo

```text
[ Buscar listas..._________________________ ]
┌────────────────────────────────────────────┐
│ Nochevieja              Editar ›    [x] │
│ 3 ítems  0/3 hechos                       │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. Lógica

- Ítems comprados/pendientes; **Restablecer** con confirmación.
- Vínculo con ocasión bloquea borrado.
- Duplicar crea lista nueva.

## 7. Notas

- **Premium** posible.
- La guía web requiere internet; la lista funciona en la app.
