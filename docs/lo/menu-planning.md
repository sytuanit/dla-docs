# ແຜນອາຫານຕາມອາທິດ

## 1. ຈຸດປະສົງ

**ແຜນອາຫານຕາມອາທິດ**: ນຳເມນູຈາກ **ສະດາອາຫານ** ໄປໃສ່ **ເຊົ້າ / ທ່ຽງ / ແລງ** ແຕ່ລະມື້ (ຈັນອາທິດ), ກຳນົດ **ມື້ບໍ່ປຸງ**, ເບິ່ງ **ສະຫຼຸບອາທິດ**, **ສຳເນົາ** ຈາກອາທິດທີ່ມີແລ້ວ.

## 2. ເມື່ອໃດຄວນໃຊ້

- ວາງແຜນກ່ອນໄປຊື້ເຄື່ອງ.
- ຕ້ອງມີ **ຢ່າງໜ້ອຍໜຶ່ງສະດາ** ໃນ **ສະດາອາຫານ** ກ່ອນສ້າງແຜນໃໝ່.

## 3. ໜ້າຈໍ

- **ຟັງຊັນ** → **ແຜນອາຫານ** — ລາຍການ (ໃກ້ຈະມາ / ປັດຈຸບັນ / ຜ່ານມາ)
- **ສ້າງແຜນອາທິດ** — ວັນເລີ່ມ, ສຳເນົາໄດ້
- **ລາຍລະອຽດ** — ຕາຕະລາງມື້×ມື້; ກິນຂ້າງນອກ; ມື້ພັກ; ສະຫຼຸບ; ອາທິດກ່ອນ

## 4. ວິທີໃຊ້

**ສ້າງ** → ເລືອກວັນເລີ່ມ → ວັນທີ **ຊ້ຳກັນ** ກັບແຜນເກົ່າ = ຜິດພາດ. ບໍ່ມີສະດາ = ບໍ່ໃຫ້ສ້າງ.

ແຕະຊ່ອງມື້ → **ເລືອກສະດາ** ຫຼື **ກິນຂ້າງນອກ**

**ບໍ່ປຸງມື້ນີ້** — ມີຄຳເຕືອນ; **ເປີດປຸງອີກຄັ້ງ**

ລຶບອາທິດຈາກລາຍການ.

**ຈຳກັດ 12 ແຜນ** — ອາດມີກ່ອງໂຕ້ຕອບ.
