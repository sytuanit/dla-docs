# สูตรอาหาร

## 1. วัตถุประสงค์

โมดูล **สูตรอาหาร** ใช้เก็บ **สูตรทำอาหาร** (ชื่อ, วัตถุดิบ, วิธีทำ), **ประเภทโปรตีน**, **ให้คะแนนดาว**, และจัดกลุ่มเป็น **คอลเลกชัน** ข้อมูลใช้ร่วมกับ **วางแผนเมนู** เมื่อใส่มื้อในแต่ละวันของสัปดาห์

## 2. เมื่อไหร่ควรใช้

- ต้องการสมุดสูตรส่วนตัว
- จัดกลุ่มด้วย **คอลเลกชัน**
- ก่อนใช้ **วางแผนเมนู** ต้องมี **อย่างน้อยบางสูตร** ใน **สูตรอาหาร** ก่อน

## 3. หน้าจอที่เกี่ยวข้อง

- **ฟังก์ชัน** → **ครัว** → **สูตรอาหาร**
- แท็บ **สูตรทั้งหมด** / **คอลเลกชัน**
- **เพิ่มสูตร** / **แก้ไข**
- **รายละเอียดคอลเลกชัน**

## 4. การใช้งานหลัก

**ฟังก์ชัน** → **สูตรอาหาร** → **ค้นหาสูตร...** ; แท็บ **คอลเลกชัน**

**+** (FAB) → **ชื่อเมนู** (จำเป็น), **โปรตีน** (คั่นด้วยจุลภาค), **คะแนน**, **วัตถุดิบ** (อย่างน้อยหนึ่งรายการ), **วิธีทำ**, **คอลเลกชัน** → **บันทึก**

แตะสูตรเพื่อแก้ไข **ลบ** หากใช้ใน **แผนมื้อ** จะมีคำเตือน

**คอลเลกชัน** → สร้างใหม่; เปิด → **เพิ่มสูตร**; เปลี่ยนชื่อ/ลบคอลเลกชัน (ไม่ลบสูตร)

## 5. ตัวอย่าง

```text
[ สูตร ]  [ คอลเลกชัน ]
[ ค้นหา...______________________________ ]

┌────────────────────────────────────────────┐
│ ต้มยำกุ้ง                         [ x ] │
│ ★★★★☆  ·  โปรตีน: ทะเล                  │
│ 5 รายการ  ·  คอลเลกชัน: ไทย           │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. กฎ

- ต้องมี **วัตถุดิบอย่างน้อยหนึ่งรายการ**
- ลบสูตรที่อยู่ในแผน: ต้องยืนยัน

## 7. หมายเหตุ

- อาจมีป้าย **พรีเมียม** ที่ **ฟังก์ชัน**
