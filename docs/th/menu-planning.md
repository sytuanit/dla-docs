# วางแผนเมนู

## 1. วัตถุประสงค์

**วางแผนเมนู** (รายสัปดาห์): นำเมนูจาก **สูตรอาหาร** ไปใส่ **เช้า / กลางวัน / เย็น** แต่ละวัน (จ-อา), ทำเครื่องหมาย **วันไม่ทำอาหาร**, ดู **สรุปสัปดาห์**, **คัดลอก** จากสัปดาห์ที่มีแล้ว

## 2. เมื่อไหร่ควรใช้

- วางแผนก่อนไปซื้อของ
- ต้องมี **อย่างน้อยหนึ่งสูตร** ใน **สูตรอาหาร** ก่อนสร้างแผนใหม่

## 3. หน้าจอ

- **ฟังก์ชัน** → **วางแผนเมนู** — รายการแผน (เร็วๆ นี้ / ปัจจุบัน / อดีต)
- **สร้างแผนรายสัปดาห์** — วันเริ่ม, คัดลอกได้
- **รายละเอียด** — ตารางวัน×มื้อ; กินนอก; วันหยุดทำ; สรุป; สัปดาห์ก่อน

## 4. การใช้งาน

**สร้าง** → เลือกวันเริ่ม → วันที่ **ทับซ้อน** กับแผนเดิม = ข้อผิดพลาด ไม่มีสูตร = สร้างไม่ได้

แตะช่องมื้อ → **เลือกสูตร** หรือ **กินนอก**

**ไม่ทำอาหารวันนี้** — มีคำเตือน; **เปิดทำอาหารอีกครั้ง**

ลบสัปดาห์จากรายการ

**จำกัด 12 แผน** — อาจมีกล่องโต้ตอบ

## 5. ตัวอย่าง

```text
[ สัปดาห์: 03/01 – 09/01 ]  [🟢 ปัจจุบัน]
```

## 6. กฎ

- 7 วัน ไม่ทับช่วงวันกับแผนอื่น
- เมนูจาก **สูตรอาหาร** กินนอกเป็นข้อความ

## 7. หมายเหตุ

- **พรีเมียม** เป็นได้
- เพิ่มสูตรก่อนแผนแรก
