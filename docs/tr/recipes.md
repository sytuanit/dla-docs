# Tarifler

## 1. Amaç

**Tarifler** modülü **yemek tariflerini** (ad, malzemeler, hazırlanış), **protein türleri**, **yıldız puanı** ve **koleksiyonlar** ile düzenlemenizi sağlar. Veriler **Menü planlama**da haftalık öğünlere atanır.

## 2. Ne zaman?

- Kişisel tarif defteri.
- **Koleksiyonlar** ile gruplama.
- **Menü planlama** için önce **en az birkaç tarif** gerekir.

## 3. İlgili ekranlar

- **İşlevler** → **Mutfak** → **Tarifler**
- **Tarifler** / **Koleksiyonlar** sekmeleri
- **Tarif ekle** / **Düzenle**
- **Koleksiyon detayı**

## 4. Kullanım

**İşlevler** → **Tarifler** → **Ara...** ; **Koleksiyonlar**.

**+** → **Yemek adı** (zorunlu), **Protein**, **Puan**, **Malzemeler** (en az bir satır), **Hazırlanış**, **Koleksiyonlar** → **Kaydet**.

Düzenlemek için tarife dokunun. **Haftalık menüde** kullanılıyorsa silmeden önce uyarı.

## 5. Örnek

```text
[ Tarifler ]  [ Koleksiyonlar ]
[ Ara..._________________________________ ]

┌────────────────────────────────────────────┐
│ Tom yum çorbası                    [ x ]  │
│ ★★★★☆  ·  Protein: deniz ürünü           │
│ 5 malzeme  ·  Koleksiyon: Tay           │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. Mantık

- En az **bir malzeme** zorunlu.
- Menüde kullanılan tarif: onay ile plandan çıkar.

## 7. Notlar

- **Premium** rozeti **İşlevler**de olabilir.
