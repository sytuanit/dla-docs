# Speiseplan

## 1. Zweck

**Speiseplan** (wöchentliche Essensplanung): Gerichte aus **Rezepte** in **Frühstück / Mittagessen / Abendessen** pro Tag (Mo–So) eintragen, **kochfreie Tage**, **Wochenübersicht** und **Kopieren** aus einer bestehenden Woche.

## 2. Wann nutzen?

- Wochenplanung vor dem Einkauf.
- Mindestens **ein Rezept** in **Rezepte** nötig zum Anlegen.

## 3. Bildschirme

- **Funktionen** → **Speiseplan** — Liste der Wochenpläne (Status: bevorstehend / aktuell / vergangen)
- **Wochenplan erstellen** — Startdatum, optional Kopie
- **Detail** — Raster nach Tag und Mahlzeit; externe Gerichte; kochfrei; Übersicht; Vorwoche

## 4. Hauptbedienung

### 4.1 Neue Woche

Funktionen → Speiseplan → **Wochenplan erstellen** → Startdatum → optional **Aus Plan kopieren** → bei **Datumsüberschneidung** Fehler.

Ohne Rezepte: Anlegen blockiert.

### 4.2 Gerichte zuweisen

Mahlzeit-Slot antippen → **Rezept wählen** oder **Externes Gericht** (Freitext).

### 4.3 Kochfreier Tag

**Heute nicht kochen** → optional Grund → Warnung löscht Tagesgerichte; **Kochen wieder aktivieren** möglich.

### 4.4 Übersicht / Vorwoche

**Wochenübersicht** und **Vorwoche** je nach App.

### 4.5 Löschen

Woche in der Liste löschen — bestätigen.

**Limit**: **12 Pläne** — bei Grenze Dialog (älteste Woche kann entfernt werden).

## 5. Beispiele

### 5.1 MEAL-01

```text
[ Woche: 03.01. – 09.01. ]   [🟢 Aktuell]
        Mo    Di    Mi
Frühst. [+]   [+]   [+]
Mittag  [+] [Tom Yum][+]
Abend   [+]   [+]   [+]
```

### 5.2 MEAL-02: Auswärts

Samstag: **Nicht kochen** oder externes Gericht.

## 6. Logik & Regeln

- 7 Tage; keine überlappenden Zeiträume.
- Gerichte aus **Rezepte**; externe Einträge als Freitext.
- **12-Plan-Limit** — siehe Dialog.

## 7. Hinweise

- **Premium** möglich.
- Rezepte vor erstem neuen Plan anlegen.
