# Belanja (checklist)

## 1. Tujuan

**Belanja (checklist)**: daftar item, **centang**, **edit**, **salin**, **hapus**. Tautan ke **Acara khusus** — **hapus diblokir** jika sedang dipakai.

## 2. Kapan digunakan

- Belanja dengan daftar jelas.
- Menduplikasi untuk acara serupa.
- Checklist di langkah persiapan.

## 3. Layar

- **Fungsi** → **Belanja (checklist)**
- **Buat / Edit**
- **Gunakan checklist** — centang, tambah cepat, **Reset**
- **Acara khusus** — pilih checklist

## 4. Penggunaan

**+** → nama → item → **Simpan**. **Edit ›**; salin dari daftar; hapus (tertaut = ditolak). **Cari checklist...**

## 5. Contoh

```text
[ Cari...________________________________ ]
┌────────────────────────────────────────────┐
│ Tahun Baru                Edit ›      [x] │
│ 3 item  0/3 selesai                      │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. Logika

- **Reset** dengan konfirmasi.
- Tautan acara memblokir hapus.

## 7. Catatan

- **Premium** mungkin.
- Panduan web perlu internet.
