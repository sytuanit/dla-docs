# Spesa (checklist)

## 1. Scopo

**Spesa (checklist)**: liste con voci, **spunta**, **modifica**, **duplica**, **elimina**. Collegamento a **Occasioni speciali** — **eliminazione bloccata** se in uso.

## 2. Quando usarlo

- Lista chiara per la spesa.
- Duplicare per eventi simili.
- Checklist negli step di preparazione.

## 3. Schermate

- **Funzioni** → **Spesa (checklist)**
- **Crea / Modifica**
- **Usa checklist** — spunta, aggiunta rapida, **Reimposta**
- **Occasioni speciali** — scelta checklist

## 4. Uso

**+** → nome → voci → **Salva**. Tocca lista per usare; **Modifica ›**; copia; elimina (bloccato se collegata). **Cerca checklist...**

## 5. Esempio

```text
[ Cerca..._______________________________ ]
┌────────────────────────────────────────────┐
│ Capodanno                 Modifica ›  [x] │
│ 3 voci  0/3 completate                    │
└────────────────────────────────────────────┘
                                             [ + ]
```

## 6. Logica

- Voci completate/pendenti; **Reimposta** con conferma.
- Collegamento occasioni blocca eliminazione.
